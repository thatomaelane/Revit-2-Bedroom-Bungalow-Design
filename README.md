# Project Overview

This project showcases the complete architectural design of a modern **2-bedroom bungalow** developed using **Autodesk Revit** and **AutoCAD**. The project follows the Building Information Modeling (BIM) workflow to create accurate architectural plans, elevations, sections, and realistic 3D views.

The design process began with drafting the floor plan in AutoCAD before developing a detailed BIM model in Revit. The final model includes building components such as walls, doors, windows, roofing, floors, and room layouts while maintaining engineering accuracy and architectural standards.

Project renders and additional visuals are available on my Behance portfolio.

# BIM Workflow

The project followed these stages:

1. Concept Planning
2. AutoCAD Floor Plan Drafting
3. Revit BIM Modeling
4. Wall & Floor Creation
5. Door & Window Placement
6. Roof Modeling
7. Room Layout
8. Elevation Generation
9. Section Creation
10. 3D Visualization
11. Final Documentation
